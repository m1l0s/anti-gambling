# Anti-Gambling Filter Lists

AdGuard filter liste za blokiranje gambling sadržaja na Balkanu.

## Liste

### Balkan Anti-Gambling List (`balkan.txt`)
Blokira **same sajtove** kladionica i kazina popularnih na Balkanu (RS, HR, BA...).

**Subscription URL:**
```
https://raw.githubusercontent.com/m1l0s/anti-gambling/main/balkan.txt
```

### Lite Anti-Gambling AdNetwork Filter (`lite.txt`)
Blokira samo **reklame, skripte i affiliate/tracking mreže** — sajtovi ostaju dostupni.
Korisno za one koji ne žele da blokiraju cele sajtove ali hoće da uklone gambling reklame.

**Subscription URL:**
```
https://raw.githubusercontent.com/m1l0s/anti-gambling/main/lite.txt
```

## Kako dodati u AdGuard

1. Otvori **AdGuard** → **Filteri** → **Prilagođeni filteri**
2. Klikni **Dodaj prilagođeni filter**
3. Nalepi subscription URL i potvrdi

AdGuard će automatski osvežavati liste svakih 7 dana.
